# security-log-analyzer
A python project that will analyze sample security logs and summarize authentication activity

October 12 2026

1. What problem will this project solve?
  This will help security analysts automate the review of authentication log files. Giving the analysts time to focus on logins denied due to multi failed login attempts.

2. Who might use it?
  Security Analysts that ingest huge authentication log files on a daily basis that want to spend more time reviewing potential authentication risks.

3. What do you eventually want it to do?
  Version 1 of this project will ingest and review authentication logs and provide a summary of successful logins as well as logins denied based on the number of failed login attempts.
