# security-log-analyzer
A python project that will analyze sample security logs and summarizes authentication activity

October 12 2026

1. What problem will this project solve?
  This will help security analyst review huge security files while being able to focus on actual attempted attacks

2. Who might use it?
  Security Analyst that ingest huge security log files on a daily basis that want to spend more time reviewing potential security risks

3. What do you eventually want it to do?
  Eventually I would like this project to be able to ingest all the log files from a company, do a basic review of the information and categorizes it so that analyst's can easily decide what to focus on first.
